# 📚 WordMaster - 國中英語單字英雄榜

WordMaster 是一款專為國中生與英語初學者設計的**響應式單字學習 Web 應用程式**。結合單字記憶、語法觀念、多樣化 Gamified 遊戲互動機制與道具商城，讓背單字變得輕鬆又趣味十足！

🚀 **線上即時體驗**：[WordMaster 官方網站](https://wordmaster-1-one.vercel.app)

---

## ✨ 核心特色功能

### 📚 1. 全功能單字庫與分頁系統
- **單字分類與篩選**：支援名詞 (n.)、動詞 (v.)、形容詞 (adj.) 等詞性快速過濾。
- **清爽分頁機制**：一次僅顯示 15 個單字，徹底消除大量文字帶來的視覺壓迫感。
- **語意與語法解析**：內建 KK 音標、詞性標籤、語法觀念提示與真人 TTS 語音發音。

### 🎮 2. 豐富的遊戲競技場
- **⚡ 4選1極速PK賽**：標準選擇題模式，考驗即時翻譯能力。
- **🌧️ 單字瀑布接接樂**：結合動態下落機制的接單字小遊戲。
- **🔤 點擊拼字大挑戰**：組合字母碎片拼出完整單字。
- **🧩 句子重組大挑戰**：練習英文正確語順與句型結構。
- **❤️ HP 3心生存模式**：答錯即扣心，挑戰無盡關卡極限！

### 🏆 3. 英雄排行榜與個人成就
- **全球英雄榜**：即時計算分數與名次，搶奪🥇冠、🥈亞、🥉季軍光輝頭銜。
- **成就勳章牆**：達到指定條件自動解鎖勳章（初出茅廬、神準神射手、金幣大亨等）。

### 🛍️ 4. 道具商城與個人化外觀
- **功能道具**：可使用遊戲賺取的金幣購買「二選一排除卡」、「凍結沙漏」與「HP補血藥水」。
- **炫彩外觀**：提供各種專屬稱號與外框效果，自由切換個人個人檔案。

### 📕 5. 專屬錯題本與備份機制
- **自動紀錄錯題**：遊戲中答錯的單字自動歸檔至錯題本，精準打擊記憶弱點。
- **JSON 備份與還原**：支援一鍵匯出/匯入個人學習歷程。
- **☁️ Supabase 雲端 Auth 整合**：支援使用者帳號註冊與登入，邁向跨裝置同步。

## 🛠️ 技術架構

- **前端**：HTML5, CSS3 (Modern Flexbox/Grid, Mobile-First 抽屜選單), Vanilla JavaScript (ES6+)
- **資料儲存**：`localStorage` (本地持久化) / Supabase (雲端身份驗證)
- **部署平台**：Vercel
- **第三方 API / 庫**：
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) (獲勝慶祝特效)
  - Web Speech API (瀏覽器原生發音)
